SSH into Raspberry Pi from Android Termux via Cloudflare Tunnel

Connect to your home Raspberry Pi from your phone using Termux, cloudflared, and a proot Alpine Linux environment.

Background

If you already SSH into your Raspberry Pi from a Mac using a Cloudflare Tunnel with a ProxyCommand in your SSH config, you might want the same access from your Android phone. The challenge is that cloudflared doesn't run natively in Termux.. Termux's linker can't handle standard Linux ELF binaries, giving you the dreaded unexpected e_type: 2 error.

The fix: run cloudflared inside an Alpine Linux proot environment within Termux.

Prerequisites

  • 🍓 Raspberry Pi with a Cloudflare Tunnel running
  • 📱 Android phone with Termux installed
  • 💻 A Mac (or other machine) that can already SSH into the Pi

Step 1: Install proot-distro & Alpine

Since cloudflared binaries won't run directly in Termux, we install a lightweight Linux distro via proot-distro.

pkg update
pkg install proot-distro
proot-distro install alpine

Step 2: Install cloudflared inside Alpine

Log into the Alpine environment and download the cloudflared binary manually, since it's not available in Alpine's package repos.

proot-distro login alpine
apk add wget
wget https://github.com/cloudflare/cloudflared/releases/latest/download/cloudflared-linux-arm64
chmod +x cloudflared-linux-arm64
mv cloudflared-linux-arm64 /usr/local/bin/cloudflared

Verify it works:

cloudflared --version

✅ If you see a version number, cloudflared is working. Type exit to return to Termux.

⚠️ If your device is older / 32-bit ARM, use cloudflared-linux-arm instead of cloudflared-linux-arm64.

Step 3: Generate an SSH key in Termux

Back in Termux (not Alpine), generate an SSH key pair if you don't already have one:

ssh-keygen -t ed25519

Press Enter to accept defaults. Then view your public key:

cat ~/.ssh/id_ed25519.pub

Copy this entire output - you'll need it in the next step.

Step 4: Add the public key to your Raspberry Pi

From your Mac (or any machine that already has SSH access to the Pi), add the Termux public key to the Pi's authorized keys:

ssh sub-domain.domain.com "echo 'YOUR_TERMUX_PUBLIC_KEY' >> ~/.ssh/authorized_keys"

📋 Replace YOUR_TERMUX_PUBLIC_KEY with the full output from cat ~/.ssh/id_ed25519.pub on Termux.

Step 5: Configure SSH in Termux

mkdir -p ~/.ssh
vi ~/.ssh/config

Add the following:

Host sub-domain.domain.com
    User pi
    IdentityFile ~/.ssh/id_ed25519
    ProxyCommand proot-distro login alpine -- cloudflared access ssh --hostname %h

Step 6: Connect!

ssh sub-domain.domain.com

🎉 You should now be connected to your Raspberry Pi from your phone.

Troubleshooting

unexpected e_type: 2 — You're trying to run cloudflared directly in Termux. Make sure you're running it inside the Alpine proot environment.

Permission denied (publickey) — Your Termux public key hasn't been added to the Pi's ~/.ssh/authorized_keys. Follow Step 4.

Cloudflare Access login prompt — If your tunnel uses Cloudflare Access authentication, install the termux-api package and the Termux:API app so the browser can open for login.
